# Contributing to a/declassified

Share a Post or Artifact from the Wall, https://abstracts.co/a/declassified/wall, or open a pull request here. Maintainers (starting with @AGZ-TX) accept or close it.

Use the Artifact cube for a bundle in `artifacts/<id>/`; check its title and cover, then Post. To add a file to the explorer, follow [skills/add-a-file](skills/add-a-file/SKILL.md): its pages and media go to [abstracts-co/declassified-data](https://github.com/abstracts-co/declassified-data) and its index comes here, in one pull request each. Text, photos, links and notes stay Discussions. Configuration uses native repository writer tools.
